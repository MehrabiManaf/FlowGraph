## System

### For Each Output Line

`system.lines` · exec · from system

Runs a program and the loop body for each line it writes, as the lines come (tail -f, a log, a build): the node waits for the next line, the application does not. Lines of the standard output and of the standard error come in the order they were read. Completed when the program has ended and every line was handled; a Break ends the loop and kills the program. Exit Code is -1 until the program has ended (and after a Break). The program's standard input is empty. A program that writes to a pipe instead of a terminal may hold its output back until its buffer is full. Text that is not UTF-8 is read in the OEM code page on Windows (the one of cmd.exe's own commands). A program that cannot be started (not found, no such working directory) is a script error. The program never outlives the script: stopping it, a hot reload or the end of the instance kill it and everything it started.
